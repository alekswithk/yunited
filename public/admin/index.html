        How to use this page

        Everything you change here is saved straight to the website. There is nothing to install and nothing to log into beyond the Cloudflare screen you already passed.

        Adding an event

        1. Make sure the Events tab is selected, then press Add event.
        2. Fill in the fields — only three are required:
          • Title (required) — the name on the card. Example: Casino Night.
          • Description (required) — a sentence or three: what it is, who it's for, anything to bring. Example: “Roulette, blackjack and a dress code. Chips on arrival, prizes at midnight.”
          • Photo (required) — a landscape (wide) picture; see Photos below.
          • Date (optional) — leave it empty if it isn't fixed. The event then appears at the top of Upcoming as “date to be announced”.
          • Start time (optional) — e.g. 20:30. Leave empty if there's no fixed start.
          • Location (optional) — venue or address, e.g. Déjà Vu Bar, St. Gallen. If you leave it empty the card simply doesn't show a location line.
          • RSVP / ticket link (optional) — paste the whole address including the https://. Leave empty and the card shows no button.
        3. Press Save. You'll get a green confirmation, or a message telling you exactly what's missing.

        You never mark an event as “past”. The website compares the date to today and files it under Upcoming or Past by itself. An event with no date is always treated as upcoming.

        Finding something in the list

        Use Sort by above the list. Events start with the newest first (anything without a date yet sits at the very top, since that's what still needs planning), and you can switch to oldest first or A–Z. Board members and partners start in the order they appear on the website — 1, 2, 3 — and can be sorted by name instead. Each section remembers what you picked while you're on the page.

        Editing or removing an event

        • Edit: press Edit on the event in the list, change what you need, press Save. Leaving the photo control alone keeps the current photo.
        • Remove: open it with Edit and press Delete… at the bottom. You'll be asked to confirm. This removes the event and its photo from the site for good — past events are worth keeping, so only delete something added by mistake.

        Board members

        Same idea, under the Board members tab.

        • Role (required) — e.g. Head of Events. Roles are used in English at HSG, so write it in English.
        • Order (required) — 1 is the President and gets the big card, then 2, 3, … Every member needs a different number; if you swap two people around, change both.
        • Name (optional) — leave it empty if the seat is filled but not announced yet; the card then says “To be announced”.
        • Short bio (optional) — a line or two in their own words.
        • Portrait (optional) — without one the card shows their initial.

        A board member's name, role and bio appear exactly as you type them on every language's page. They are never machine-translated — that is deliberate, so nobody's own words get mangled.

        Partners

        For companies that support the club. Name and order are required; the website link and the logo are optional. The logo strip on the Partners page only appears once there is at least one partner here.

        Access

        The Access tab is the list of people who can open this page. It is the real thing, not a copy of it — a change here takes effect within seconds, and there is no separate step in the Cloudflare dashboard.

        • Adding someone: type their email address and press Add. They can sign in immediately: they go to yunited.ch/admin, type that same address, and Cloudflare emails them a one-time code. No account to create, nothing to install.
        • Use the address they will actually type. The code goes to that mailbox, so an old or misspelled address means nobody can sign in with it — it doesn't fail loudly, it just never arrives.
        • Removing someone: press Remove and confirm. Their access ends at once. This is the whole off-boarding step when someone leaves the board — they never had a password of their own.

        Two things the page will not let you do, both to stop the board locking itself out: you cannot remove your own address, and you cannot remove the last one. To hand over your own seat, add the new person first and ask them to remove you.

        Anyone on the list can change the list. Every change is logged with the email of whoever made it. If the list is ever emptied by accident — which this page refuses to do, but a mistake in the Cloudflare dashboard could — whoever looks after the Cloudflare account can restore it there.

        Photos

        • Format: JPG, PNG or WebP. iPhone photos are often HEIC and won't work — share or export the photo first and it saves as JPEG.
        • Size: under 1 MB is ideal; 5 MB is the hard limit. Bigger files just make saving slow — the website shrinks them for you anyway.
        • Shape: events want a landscape (wide) picture, board portraits want something square-ish.
        • Where they go: straight into the website's own image folder, renamed to match the entry. You don't need to name the file anything in particular. The site then makes its own resized, sharpened copies — you always upload the original.
        • Uploading a new photo for an entry replaces the old one.

        After you save

        Saving writes the change to the club's GitHub repository, which starts a rebuild of the website automatically. Reckon on:

        • 1–2 minutes, in every language at once. An event's German, Bosnian, Croatian and Serbian title and description are filled in while you save, so there is one rebuild rather than two.

        If the page still looks old after that, refresh it properly (Shift + reload).

        Translations

        Each event's row says where its translations stand — translated, not translated yet, or needs re-translating (you changed the English, so the old ones no longer match it).

        • To read or fix them, open the event and switch to its Translations page. The four languages are ordinary boxes: if one reads wrong, type over it and press Save. Several of you speak these languages better than any machine does.
        • A correction stays for as long as the English text is unchanged. Edit the title or description later and all four are filled in again — they were translations of a sentence that no longer exists.
        • Translate now re-does all four from scratch, for when a save could not reach the translator.
        • Only the title and description are translated. A location is a real place, and translating it would send people to an address that does not exist.
        • If translations stop happening, look at the Translations tab. It says whether the club's DeepL key still works, and anyone here can paste in a new free one — no developer needed. Events save normally meanwhile; they just stay in the language you wrote them in.

        If something goes wrong

        • Nothing is ever half-saved: a change either goes through completely or not at all.
        • If you get a red message, it says what to fix — usually an empty required field or a photo in the wrong format.
        • If two of you save at the same moment, the second person is asked to reload and redo their edit. Nobody's work is overwritten.
