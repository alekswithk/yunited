1. WEBSITE WORDING — the language dictionaries
----------------------------------------------
Every visible string on the site except event/member content. 161 keys each.

  src/i18n/en.json     English   SOURCE OF TRUTH — add any new string here FIRST
  src/i18n/de.json     Deutsch   reviewed + LIVE
  src/i18n/bcs.json    Bosanski + Hrvatski (one shared file, both URL prefixes)
  src/i18n/sr.json     Srpski
                       ^ bcs + sr are raw machine translation, NOT yet published

  Rules:
   - A key missing from a translation falls back to English, so nothing breaks.
   - Keys ending Pre / Link / Post are one sentence split around a link — keep
     the three parts consistent with each other.
   - Values containing <a> or <strong> are rendered as HTML; keep the tags.
   - {title} and {name} are placeholders filled in at render time. If one goes
     missing the text silently stops substituting, so leave them exactly as-is.

  After editing en.json, run:  npm run translate     (fills the other three)


2. WHICH LANGUAGES ARE PUBLIC
------------------------------
  src/i18n/config.js   one line per locale; `complete: true` publishes it.

  Today: en + de are live. bs / hr / sr are generated and viewable at their real
  URLs (/bs/, /hr/, /sr/) but are noindex, absent from the sitemap and hidden
  from the language switcher until someone flips the flag.


3. EVENTS — one file per event
-------------------------------
  content/events/*.json        (9 files; filename must match the "id" inside)

    casino-night-2026            movie-night-svadba-2026
    christmas-dinner-2025        post-midterm-brunch-2026
    global-village-2026          prvi-maj-2026
    karaoke-2026                 semester-end-party-2026
    meet-and-greet-2026

  Edit: title, date, time, location, description, image, rsvpUrl
   - Leave "date" empty for TBA — it then shows at the top of Upcoming.
   - Leave "location" empty for a venue TBA. Never type "To be announced".
   - Never mark an event past by hand; the date decides.
   - The "i18n" block is written automatically — ignore it unless you want to
     correct a translation.


4. BOARD MEMBERS — one file per seat
-------------------------------------
  content/members/*.json       (6 files)

    president            head-of-events        head-of-partnerships
    vice-president       head-of-finance       head-of-marketing

  Edit: role, name, bio, photo, order
   - "order" sets the sequence; 1 gets the large lead card.
   - Leave "name" empty for a seat that is not announced yet.
   - No "i18n" block here, unlike events: what you type is what every language
     shows. Write the bio in whichever language you want it read in.
